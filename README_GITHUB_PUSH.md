# GitHub Actions से दोनों Debug APK बनाने के 3 आसान स्टेप (P-02)

1. इस ZIP की सभी फ़ाइलों को अपनी GitHub रिपॉजिटरी (`BHACHAT-SAMUAH-PRANALI-`) के रूट में अपलोड/Push करें।
2. GitHub पर **Actions** टैब खोलें — `Bachat Samuh Android CI (Test + Dual APK Build)` वर्कफ़्लो अपने-आप चलेगा (या **Run workflow** दबाएँ)।
3. बिल्ड हरा (Green PASS) होते ही नीचे **Artifacts** से `bachat-samuh-admin-and-agent-apks` डाउनलोड करें — उसमें `adminApp-debug.apk` और `agentApp-debug.apk` दोनों तैयार मिलेंगे।
